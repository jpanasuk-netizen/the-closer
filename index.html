Independent lab

AI Systems Engineer · Local AI Lab

A private RTX 4070 lab built with Docker Compose, CUDA, TabbyAPI/EXL3, Ollama, MCP, SQLite telemetry, and RAG. The point is not a demo. Every claim gets a benchmark, a regression check, and a documented operating path — the same loop I used on Grid/HA. Four agents run as four isolated Python processes, each with its own virtual environment, handing Pydantic JSON instead of free text: Systems names the constraints, Architect writes the contract, Synthesis generates against local Ollama, Validator checks schema and graph and self-heals until it passes. If one agent crashes, the other three keep running. n8n RAG pulls live competitive telemetry, writes a Discord briefing every run, and only fires WhatsApp when the score hits a threshold or Rank 1 territory. Real-world performance

Baseline, then a named goal, then the bottleneck, then eliminate it, then repeat. Thread statistics before folklore. Do not partition a single-partition mystery. Cache large transformations in RAM so they stop spilling to disk — Mercedes-Benz Financial took 20–30% off job runtime that way and kept the cheat sheet. Isolation tests before you add another box.
